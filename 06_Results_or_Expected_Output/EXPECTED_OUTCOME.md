# Preliminary and expected output

The generated risk register is an example of the proposed output, using synthetic records. It should demonstrate:

- ranking of critical and high risks;
- separate CIA input values;
- transparent initial and residual calculations;
- linkage to treatment, framework outcome, owner and evidence; and
- an action-oriented view that an SME can review.

These are preliminary scenario results. They must not be presented as findings collected from real Malaysian companies.
