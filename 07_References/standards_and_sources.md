# Standards, research and attribution

## Core standards and official guidance

- ISO/IEC 27001:2022 information page: https://www.iso.org/standard/27001
- ISO/IEC 27005:2022 information page: https://www.iso.org/standard/80585.html
- NIST Cybersecurity Framework 2.0: https://doi.org/10.6028/NIST.CSWP.29
- NIST SP 800-30 Rev. 1: https://doi.org/10.6028/NIST.SP.800-30r1
- NIST CSF 2.0 Small Business Quick-Start Guide: https://doi.org/10.6028/NIST.SP.1300

This repository uses original summaries and public outcome labels. It does not reproduce copyrighted ISO standard text.
